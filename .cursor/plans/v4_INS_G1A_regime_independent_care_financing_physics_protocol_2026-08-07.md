## §0 — What this experiment was, and why it was run this way

Gate 0 established that OMNI's financing framing was still reasoning **from the US payer system outward.** Gate 1a asked the inverse question — *what care-financing physics survive any financing regime, including none at all* — and asked it of an agent deliberately **blind** to OMNI's own decomposition, so that convergence would be informative rather than an echo.

**The methodological defect this protocol exists to correct.** An earlier single-block draft instructed the agent to *"generate your own regimes before reading the list below."* That is not an information wall: the whole prompt sits in context at once, so the agent could comply rhetorically while having already seen the list. Knox identified this and it is correct. **The fix is two messages in one thread**, which creates a genuine wall because the Phase-B content does not exist in context during Phase A.

**Why the same thread for both phases.** Phase B must hold Phase A in context to produce an honest change ledger. The separation is **informational, not two models.**

**Three protections carried into the design:**
- **Inheritance filter** — without it the agent returns provenance, authority, append-only correction, uncertainty and multi-axis time as though it had discovered them *for financing*, which would be a **false convergence signal**: our own inputs echoed back as validation. Phase A therefore requires a shown derivation attempt against the given substrate principles, and demotion is a success.
- **Normative/descriptive split** — "physics" must not silently blend structural necessity, ethical commitment, policy choice and empirical assumption, or the resulting laws cannot be falsified because nobody knows what kind of claim they are.
- **Withheld anchors** — the multi-authority verification report, the five-zone model, H-N1/H-N2/H-N3, agreement-as-object, D6, and PR #4 were **all withheld from both phases.** The verification report in particular encodes the incumbent gap hypothesis and would have anchored the agent on the exact question under debate.

## Closure Policy Lock (Draft v1)

- Allowed `resolution_status` values: `open_review`, `split_review`, `needs_catalog_update`, `partially_resolved`, `resolved`.
- A row may enter `resolved` only when all of the following are present in `notes`:
  - explicit winning authority path,
  - explicit closure criteria/result,
  - supersession link (`superseded_by`) if a replacement artifact exists,
  - review gate outcome when `review_gate != none`.
- Any unresolved row with `severity: critical` must keep an owner and review gate populated.
- Rows linked from open-review parent closures must preserve stable IDs (no renumbering/recycling).

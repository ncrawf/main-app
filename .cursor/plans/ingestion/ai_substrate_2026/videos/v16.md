## 2. ChatGPT distillation

<Ingested.

This one belongs in the retrieval evolution / agentic RAG / decision-to-look architecture bucket.

Core arc captured:

Keyword search → semantic search → hybrid retrieval → traditional RAG → reranked/query-expanded RAG → agentic RAG.

The biggest OMNI concept is this line:

The hardest part of AI isn’t generation; it’s deciding what to look at.

That is extremely relevant.

OMNI implication:

A basic RAG system retrieves once and answers.
An agentic RAG system decides:

whether retrieval is needed
where to search
which source type matters
whether to use keyword, semantic, graph, or hybrid retrieval
whether to rewrite/expand the query
whether it has enough information
whether sources conflict
whether to retrieve again
whether to escalate or ask for clarification
when to stop and synthesize

For OMNI, this supports a formal Retrieval Decision Layer or Context Router inside the AI substrate.

Important captured concepts:

Keyword search is still useful
Exact terms, codes, IDs, medication names, policy names, CPT/lab/test names, order IDs, appointment IDs.
Semantic search captures meaning
Useful for patient messages, documents, notes, vague symptoms, natural-language requests, internal docs.
Hybrid retrieval is likely the default
OMNI should not be purely vector search. It needs keyword precision + semantic recall.
Reranking and query expansion are required
The first retrieval pass is not enough for high-stakes workflows.
Agentic RAG treats retrieval as a tool
Retrieval is no longer a fixed pipeline. The agent can decide to search again, compare sources, validate claims, invoke APIs, pull from multiple knowledge bases, and synthesize.
Retrieval itself needs governance
The agent should not freely search everything. Federation, RBAC, consent, operator boundary, role, time, and policy should shape where it can look.

The phrase I’d preserve:

OMNI should not merely retrieve context. OMNI should reason about what context is needed, where it is allowed to come from, whether it is enough, and whether it is safe to act on.

This directly feeds the eventual AI substrate map: Context Router + Retrieval Decision Layer + Hybrid Retrieval + Reranking + Query Expansion + Source Conflict Handling + Traceable Context Assembly.>

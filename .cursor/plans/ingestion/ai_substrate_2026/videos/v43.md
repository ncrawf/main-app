## 2. ChatGPT distillation

<Ingested — this one belongs in the OMNI Evaluation / Runtime Proof / AI Governance spine.

Core takeaway: LLM-as-a-judge is useful, but it is not truth. It is a scalable evaluation mechanism that can inspect AI outputs faster than humans, but it carries its own failure modes: positional bias, verbosity bias, self-enhancement bias, and rubric drift. The transcript frames two major strategies: direct rubric-based assessment and pairwise comparison/ranking, with combined approaches useful when you need compliance scoring plus subjective quality ranking.

OMNI translation:

1. LLM judges should become evidence, not authority.
They can evaluate drafts, summaries, tool choices, retrieval quality, care-plan explanations, message tone, intake extraction, and build-agent outputs. But they cannot be the final clinical, legal, payment, consent, or deployment authority.

2. OMNI needs multiple eval types.
This maps cleanly into:

Component evals: extraction accuracy, tool-call correctness, retrieval quality, policy adherence.
End-to-end evals: patient experience, provider usefulness, task completion, safety.
Rubric evals: “Did this follow the refund/consent/clinical policy?”
Pairwise evals: “Which patient-facing message is better?”
Regression evals: “Did this new prompt/model/tool break prior behavior?”
Adversarial evals: “Can this be prompt-injected, over-authorized, or tricked?”

3. Bias checks must be first-class.
OMNI should not just store “judge_score.” It needs:

rubric version
judge model/version
positional swap result
confidence / uncertainty
disagreement between judges
human override
escalation reason
final authority outcome

4. This directly strengthens Build OS Layer 4: Runtime Proof.
Before any AI workflow is called “implemented,” OMNI needs eval traces proving the system behaves under realistic, adversarial, and edge-case conditions.

Most important insertion:

An AI judge is a review instrument, not an owning domain. Its outputs are evaluative evidence routed into CNS / Runtime Proof / Governance, never canonical truth by themselves.

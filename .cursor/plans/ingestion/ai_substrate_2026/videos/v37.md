Core concept

The useful definition here:

Agent = model + tools + loop + autonomy.

That means agent risk is not just “LLM says something wrong.” It is risk across:

Inputs → process/reasoning → outputs/actions

The transcript breaks the attack surface into exactly the kind of architecture OMNI needs to own: prompts/API calls/other agents as inputs; reasoning, data, RAG, policy, and human oversight in the middle; tools, APIs, database writes, and delegated agents as outputs.

The OMNI-critical risks

The top 10 risks map almost directly onto what we’ve been calling the missing AI substrate / agent control plane:

Goal hijack — hidden instructions shift what the agent is trying to accomplish.
Tool misuse — legitimate tools cause harm because access is too broad or poorly gated.
Identity + privilege abuse — agents inherit user credentials or act without scoped identity.
Agentic supply chain — poisoned tools, prompts, MCP servers, plugins, or agent registries.
Unexpected code execution — generated code, unsafe tool chains, sandbox escape.
Memory/context poisoning — bad context persists and corrupts future decisions.
Insecure inter-agent communication — spoofed/replayed/manipulated agent messages.
Cascading failures — one error spreads through agents, tools, workflows, and state.
Human-agent trust exploitation — the human becomes the weak approval path.
Rogue agents — drift, hidden goals, reward gaming, or loss of behavioral integrity.
Why this matters for OMNI

This strengthens the argument that OMNI needs an explicit Agent Security Plane / Agent Control Plane, not just “AI policies” sprinkled across contracts.

For OMNI, every agentic action should probably carry:

agent identity
actor/user relationship
purpose of use
authority envelope
tool permission scope
time-bounded grant
context packet ID
memory read/write provenance
model/version ID
retrieval/source lineage
policy decision trace
human approval state, where applicable
reversibility class
downstream action/audit trail
Keeper doctrine

No OMNI agent should act with ambient authority.

And:

Agent autonomy must be bounded by scoped identity, scoped tools, scoped context, scoped memory, scoped purpose, and observable traces.

This also ties back to Federation. Federation becomes even more important because agentic AI creates boundary confusion: who is acting, on whose behalf, under what consent, with what authority, across which system, using which tool, toward what committed truth.

This one should go into the future AI-substrate pass as a non-negotiable security section.>

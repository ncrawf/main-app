- **One substrate across five radii** — Build → internal Operations → First-party products → Federated operators → External ecosystem, each with *different governance*, not a separate architecture per buyer.
- **Strategy composition is shared runtime infrastructure; don't collapse it all into CNS** (Build-OS / security / BIZOPS / Accountability also consume coordination).
- **Model routing without harness routing is incomplete** — route evaluated `agent_bundle`s (model + harness + policy), not naked models; vendor-portable at the control plane, model-specific at the execution plane (`model_family_harness_profile`).
- **Gated memory-writing** — reflection may *propose* learning; the memory owner determines what survives (contamination guardrail).
- **Preserve authority/safety scaffolding** — stronger models may retire steering scaffolds but must NOT retire identity, provenance, consent, audit, authority, or safety controls.
- **Degraded healthcare rails** — API-poor legacy environments need browser-automation / computer-use / fax / email-parsing / human-assisted rails, but those rails **must identify as degraded and never masquerade as reliable transactional interfaces**.
- **Cache correctness** — a cache hit is success only when the cached context is still current, authorized, coherent, properly scoped (`cache_scope_key` / `cache_invalidation_event` / `cache_provenance_record`).
- **Context ≠ memory** — context management = externalizing durable state; conversation is execution context, not canonical memory.
- **Move compute to the data**; move only the governed result + evidence into context.
- **Work-order contract shape** — an outcome-and-budget request is insufficient without **subject · purpose · authority · evidence · commit-owner · failure-routing**.
- **Govern AI spend by outcome/risk/workload**, not one token ceiling; **route by complexity AND consequence** (a simple task can be high-consequence: PHI / controlled-substance).
- **Open interface standards do not settle semantic authority** (knowledge layer supplies candidate understanding, not canonical truth).

**Ontology / federation (270):** own the grammar of safe coordination, not everyone's reality · Knowledge Reservoirs **preserve plural interpretations + their sources rather than prematurely synthesizing** · versioned/qualified **mapping-relationship types** (equivalence / broader / narrower / partial-overlap / conflict / no-mapping / context-dependence / historical-supersession) · **interlingua with declared limits, not a language empire** · don't let "care-native" become a slogan hiding one operator's care model; don't overfit one medspa workflow into healthcare ontology.

**Governance (275):** AI governance is an **operated management system**; **governance-by-design** — governance omitted from architecture cannot be repaired by late compliance; **policy must compile into runtime constraint / blocking / routing / recall / proof**; model/supplier change = system change; nonconformity ≠ defect ≠ incident ≠ harm ≠ remedy; certification opens a procurement door but does not establish trustworthy operation; governance surrounds clinical AI without replacing clinical authority.

**Observability (272):** atomic run explains local execution · **session lineage explains longitudinal behavior** · model-observability ≠ workflow-observability · trace lineage must cross model / orchestration / authorization / domain-commit seams · **call hierarchy does not prove delegation authority** · captured / persisted / viewer-specific projection tiers · partial traces need completeness + finalization states.

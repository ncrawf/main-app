1. Ontology is not merely vocabulary; it determines what the system can perceive and act upon

Haghighi begins with the image of a tree.

A botanist, spiritual healer, and computer scientist may each conceive a different tree. The disagreement is not merely over labels. It concerns where the tree ends, whether roots and fungi belong to it, whether it is an isolated object or part of a network, and what relations are considered constitutive.

When the system repeatedly generates a tree without roots, it has not simply omitted a visual feature. It has encoded a boundary: tree versus ground, object versus relation, visible object versus sustaining system.

Core takeaway

The JEPA thesis is that a model can learn useful world representations by predicting future or missing states in embedding space rather than reconstructing every raw pixel or generating every output token.

For action:

current embedded state + proposed action -> predicted next embedded state.

For planning:

search over possible action sequences,

score predicted future states against goal states,

execute the best action or action prefix,

then re-observe and replan.

OMNI translation:

For high-impact workflows, OMNI should not only generate the next message, note, patch, charge, task closure, or schedule change.

It should ask:

what state will this action create?

what downstream obligation appears?

what risk moves?

what source/domain must be consulted?

what could go wrong?

what subgoal does this action serve?

how far ahead can we trust this prediction?

## 2. ChatGPT distillation

<Ingested into the active AI substrate / OMNI build thread.

This one belongs in the procedural knowledge / Build OS / agent operating layer bucket. The key distinction is huge:

MCP = tool access.
RAG = factual knowledge.
Fine-tuning = model-weight knowledge.
Skills = procedural knowledge.

For OMNI, this is a major unlock.

The important concepts:

Agents lack procedural knowledge by default
They may know facts and reason well, but they do not automatically know the 47-step workflow for “how OMNI does X.” Skills solve that.
Skills are repeatable work instructions
A skill.md file can tell the agent when to use the skill, what workflow to follow, what scripts/assets/references to load, and how to execute a repeatable task.

Progressive disclosure is the key pattern
Agents do not load everything all the time. They load:

metadata first: name + description
full instructions only when relevant
scripts/references/assets only at point of need

This maps directly to OMNI’s Build OS and context strategy.

Skills are procedural memory
The cognitive split is clean:
semantic memory = facts / RAG / knowledge bases
episodic memory = logs / interaction history / traces
procedural memory = skills / workflows / “how we do things”
Skills + MCP is the real combo
MCP gives the agent the ability to reach tools. Skills tell it when, why, and how to use them.
Trust/security matters
Skills can include executable scripts and access local files/env/API keys. So OMNI needs skill review, versioning, permissioning, and installation governance.

OMNI relevance:

This may be the missing bridge between Build OS and agentic AI.

We may need an OMNI equivalent of:

AGENTS.md = boot doctrine / operating rules
skill.md files = repeatable procedural workflows
MCP/capability registry = tool access
RAG/context engineering = factual/domain context
traces = episodic memory / proof
evals = quality/safety verification

This directly affects AI on OMNI: how agents build, maintain, refactor, test, and reconcile the codebase without custom prompting every time.

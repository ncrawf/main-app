This one belongs in the agentic RAG / data curation / context engineering / local-runtime bucket.

Core concepts captured:

1. Agentic AI is a loop, not a one-shot answer.
Agents perceive → consult memory → reason → act → observe results → repeat toward a goal. That maps cleanly to OMNI’s CNS/action loop.

2. Coding agents are a Build OS clue.
The architect → implementer → reviewer loop is basically the AI-native version of a development team. For OMNI build, this supports a future agent work model where humans conduct the orchestra rather than manually play every instrument.

3. Agentic workflows need external information or they hallucinate.
Agents that act without reliable context make misinformed decisions. RAG/context engineering is what grounds agentic AI in actual documents, databases, policies, and records.

4. More retrieved context can degrade performance.
The transcript explicitly warns that increasing tokens may give marginal gains, then degrade accuracy because of noise/redundancy while increasing cost and latency. This reinforces: OMNI should not dump everything into the model.

5. Ingestion quality matters before retrieval quality.
The video emphasizes converting PDFs/documents into machine-readable/LLM-readable formats like Markdown with metadata, including tables, graphs, images, and nontruncated pages. OMNI implication: D7/document ingestion must be AI-ready, not just file-storage-ready.

6. Context engineering = compressed, prioritized context.
The system should use hybrid recall — semantic + keyword — then rerank, combine related chunks, and form one coherent context package for the LLM. This is very close to OMNI’s future context-packet composer.

7. Local/open-source runtimes matter.
vLLM / Llama.cpp style runtimes can preserve API compatibility while supporting data sovereignty, on-prem deployment, and KV-cache optimization. For OMNI, this matters for future regulated/operator deployments and cost control.

Phrase to preserve:

Agentic OMNI cannot just retrieve data; it must curate, compress, prioritize, govern, and trace the context it gives to agents.>

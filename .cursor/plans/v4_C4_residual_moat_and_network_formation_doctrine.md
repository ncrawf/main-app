## §1 — The residual is NOT "ontology + agents + governance" (FSG-01; the load-bearing correction; sharpens bet-memo §11 line 9)

The bet memo (§2/§3) leans on OMNI's governance depth as the differentiator. Pressure-tested against the actual 2026 frontier, that does not survive **as stated**:
- **OpenAI + Anthropic** are building the *horizontal agent substrate* — models, agent loops, MCP/tool protocols, hosted computer environments, sandboxes, durable skills, tracing, long-running harnesses, containment. These become **extremely capable and increasingly interchangeable infrastructure.**
- **Palantir** already has semantic objects+links, kinetic action types, validation + side-effects, action logs, granular security, cross-org shared ontologies, governed write-back, agents bound to scoped Ontology permissions, and AIP's model/agent/eval/ops tooling.
- **Therefore the residual cannot be "OMNI has ontology + agents + governance."** All three now exist elsewhere.

**The residual, stated precisely (FSG-01, healthcare-native qualifier per Knox patch #5 — this is the anchor that keeps it OMNI's, not a generic enterprise-network slogan):**
> **Healthcare-native, longitudinal cross-authority execution that preserves patient rights, professional authority, domain-owned truth, accepted custody, selective reopening, consequence continuity, and portable proof across independent parties — over time.**

Generic "institutionally-accepted cross-authority execution" is claimable by Visa, SWIFT, Surescripts, clearinghouses, logistics and identity networks. The OMNI residual is **narrower and stronger** precisely because it is *care-native + longitudinal + rights-preserving*. Everyone above can technically *model* it; OMNI must make it **institutionally accepted, clinically faithful, economically workable, and dramatically easier to operate** — that is product + institution + network formation, **not ontology/technology novelty.**

> **Reactor adjacency (HYPOTHESIS, not promoted — `FWREG-014` discipline):** this residual is a near-restatement of the OMNI Reactor's invariants (admissibility-before-consequence · accepted-custody · no-silent-orphaning · selective-reopening · honest projection · bounded proof — read-graph #9g). Two independent arcs converging on the Reactor's shape is a signal to TEST, not a proof to adopt. Reactor stays frozen/unpromoted.

**Estate consequence:** the bet memo's §2 "structural impossibility" conviction anchor must be **re-scoped from technical → economic/relational.** The four rivals are not barred by engineering; they are barred by their **P&L and ownership gravity** from *credibly-neutral, operator-alpha-preserving, patient-authority-first network formation*. The firewall is copyable software; **the moat is not the firewall** (§3). The memo's "crossfire-is-the-category-fingerprint" corollary survives; the "they literally cannot build it" reading does not.

Build OMNI agents as excellent *reference clients*; keep the institutional substrate **callable by** OpenAI, Anthropic, Palantir, pharmacy-native agents, and whatever follows.

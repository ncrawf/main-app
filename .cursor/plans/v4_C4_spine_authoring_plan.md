## §2 The authoring method (operationalized — spine-first → pressure → reconcile → gate)
Per the recovered method (C3 §2.1; ORIENTATION §2.1–2.8):
1. **Top-down spine draft** from the full source base + the execution-substrate frame — section by section, per the shape plan (doc #2).
2. **Per-section worktable** (the 4-lane reconciliation ledger — worktable, NOT final prose): `existing-claim (ALL sources, not just v2/v3) → corpus/arc PRESSURE → v4 rewrite → contract/primitive/build-proof impact → open-review`. Tag each idea `stable | new-pressure | candidate-canon | conflict | needs-review`.
3. **Bottom-up pressure pass:** test the drafted spine against **every** existing contract (15), control-plane concept, the System Map, the code/ADR reality lane, and the **cumulative registry** (000001 §2A + 000002 §1/§2A + tension register).
4. **Bidirectional reconciliation:** update the spine where pressure reveals stale/missing; reconcile TO the locked contract ownership boundaries (do not contradict P1 truth).
5. **Tension-register adjudication (explicit):** every tension → `settled-by-doctrine` (cite) | `v4-decision` (state + why) | `open-review` (→ `08`). No unrouted tensions (`GRD-043`).
6. **Depth discipline (C4.0):** no section authored from a routing pointer/one-liner — pull a **Depth Packet** (richest full-body articulation from registry §1 + per-source §3 Review-003 + ORIENTATION verbatim + the arc artifacts). A section FAILS if it uses the right lens NAME but loses the depth/mechanism/tension/ownership-law.
7. **Carry corpus cautions as a CLASS** (hundreds across registry/tension-register/200+ reads/ORIENTATION §2.8/Guardrail Digest) → reconcile + route each → promote load-bearing ones into the spine's non-goals/anti-patterns. Do NOT cherry-pick ~8.
8. **Timeless output (strong default):** the spine states *what OMNI IS* (positioning "is X, not Y" kept); NO dated journey/changelog narrative. The before/pressure/after lives in the worktable, not the prose.

## §2 Knox's 6 disposition questions — answered (the deliverable)
1. **Is `source_authority_map` net-new or a named view over existing source-authority/Observation/CM/D7/CNS?** → **Both: a NET-NEW named primitive that is ~80% a composition/index.** The underlying authority bits exist (CNS 7 ownership dims, Observation verification-state, CM adoption, D7 provenance), but **nothing today indexes them at FIELD granularity with a positional `repository-of-record` + `origin-plane` + `publication-lineage`.** That index is the net-new spine — and it's the only thing that can represent D-135 ("two valid truths, different planes") without corruption. **Verdict: net-new named cross-domain primitive; build it as an index, not a new truth store.**
2. **Is `trial_protocol` a domain, a cross-domain contract, or a protocol-governance object?** → **Cross-domain contract / protocol-governance object — NOT a domain.** It is a `standard_of_care_object` specialization (C3.5 P23) with a **small owned core that has TEETH (10 elements): protocol identity+version · I/E rule set · arm/cohort/randomization refs · visit schedule+windows · dose schema/regimen constraints · blinding/knowledge-partition rules · AE/SAE reporting rules+clocks · deviation taxonomy · approval/activation state · obligation graph.** It **composes** OFC (obligations/orders/admin), CNS (orchestration/windows), Settings (config), D7 (consent/protocol-doc), RBAC (delegation/attestation), Federation (sponsor/IRB/site operators), Observation (timepoints), D6 (coverage/billing), P35 (external systems), and the `knowledge_partition` axis. **Verdict: cross-domain contract with a small owned core that OWNS protocol truth (not "a document plus tasks") — NOT a standalone domain.**
3. **Is `knowledge_partition` distinct enough from RBAC/visibility to be first-class?** → **Yes.** visibility_grant = who-may-SEE (static); RBAC = who-may-ACT. knowledge_partition adds what neither expresses: **temporal masking** (blinded-until-unlock/lock; D-050), **inference-prohibition** (AI must not infer arm from ePRO; D-042), **metadata-leak prevention** (prep-time/burden could unblind; D-045), **org-role partition across operators** (sponsor-unblinded/site-blinded; D-185), and the **safety-exception** (`emergency_unblind_authority` = RBAC break-glass + notify). **Verdict: first-class axis; composes with visibility_grant+RBAC but is a state-machine they can't represent.**
4. **Is IP custody a new object or an OFC/D7/P35 relationship extension?** → **EXTEND** — reuse the C3.5-net-new `custody_chain` (originally for controlled-substance diversion), generalized to investigational product, riding OFC (fulfillment/admin) + D7 (artifacts/retention) + P35 (IRT/sponsor accountability). **The one genuinely-new sliver is `chain_of_identity`** for cell therapy (binding identity through an external manufacturer). **Verdict: extend (custody_chain) + small net-new (chain_of_identity).**
5. **Does RWE sit under `REV-174` Operating-Intelligence or need its own plane?** → **Its own SUB-plane WITHIN REV-174 Operating-Intelligence** (not a separate domain). `outcome_intelligence` (C3.5 P28) specialized for research-grade cohort/RWE; the regulatory bar (reproducible cohort-def, provenance, missingness — D-152) is met by OMNI's existing verification/adoption/eval + `case_mix_adjustment`. **OMNI should OWN this plane, not coordinate it** (Flatiron's VALID ≈ OMNI's own machinery). **Verdict: own sub-plane under REV-174.**
6. **Does P35 cleanly model ARIA/OncoEMR/OnCore/EDC/IRT/ePRO/sponsor WITHOUT shrinking OMNI to middleware?** → **Yes — and this is the anti-diminishment proof.** P35 (`external_capability` + `command_authority_boundary`, 8 modes) + the per-system **ownership-ladder posture (current→target)** models each system precisely AND keeps the ambition: each is a **rung, not a destiny**; D-173 ("incumbent refuses write-back, OMNI still owns workflow+reconciliation") proves OMNI ≠ middleware even at low write-access; the **one honest DURABLE export-target ROLE** is the locked regulatory dataset / sponsor-submission plane — a **distinct plane** (immutable audit/lineage/inspection posture), **NOT a permanent incumbent-vendor concession** (OMNI may eventually own/produce the validated Part-11/GCP-grade export environment for an operator/sponsor), where OMNI owns the feed+provenance+reconciliation. **Verdict: P35 models them cleanly; the ladder is the anti-middleware mechanism.**

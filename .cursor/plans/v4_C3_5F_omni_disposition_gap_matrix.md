## §3 — Authority-runway check (Dragon's-Egg) — the false-retreat guard

For every `overlay` / `wrap` row, does the architecture **preserve the path to deeper authority** (system-of-record · documentation/legal-record · orders/results · med-admin · billing/compliance · cross-department control), or quietly foreclose it? **(False retreat = designing OMNI as a permanent overlay and NOT laying the runway primitives = failure.)**

| runway capability | preserved? | what keeps it open (must be done in v4/contracts, not deferred away) |
|---|---|---|
| **System-of-record / legal record (F4)** | **AT RISK → must design-now** | D7 must be designed for record-grade materialization + authentication + retention + amendment NOW (even if only the wedge builds it). If v4 treats D7 as "upload bucket," the runway forecloses. **This is the #1 dragon's-egg-keeping requirement.** |
| **Orders + administration (F1/F2)** | **preserved IF** | OFC `fulfillment_order` + a first-class `medication_administration` event are ratified as extensible act-loop primitives (not outpatient-only hacks). Build the order≠admin boundary now. |
| **Encounter / ADT / movement (F5/CC3)** | **preserved IF designed-now** | D5 must be designed to become movement-stateful (encounter + ADT + LOC) even though inpatient isn't built. Naming it in v4 keeps it open; ignoring it forecloses. |
| **Billing / compliance authority (F12)** | preserved | payment≠care firewall (D6 §8.1) + doc↔bill one-way (BIZOPS) already protect this; keep them as invariants. |
| **Cross-department / cross-operator control (CC3)** | preserved IF | Federation grant layer is ratified + designed (currently deferred `REV-157`); the topology is correct, the build is staged. |
| **Interoperability (F7)** | preserved | rail-agnostic + anti-corruption doctrine (`GRD-033`) keeps OMNI from vendor-lock; interop coexistence is the wrap posture that funds the climb. |

**Verdict on the runway:** the dragon's-egg is **architecturally preservable** and mostly preserved by existing doctrine. Three distinct (non-overlapping) categories of work keep it open: (1) **one urgent runway must-do** — legal-record/system-of-record **design-now** (F4; D7 doctrine exists, so it is design-now, NOT undesigned); (2) **the highest-leverage new act-loop primitive** — `medication_administration` event (F2, order≠admin); (3) **two genuinely-undesigned gaps that need DESIGN, not just build** — degraded-mode/downtime (CC1) + movement-stateful inpatient encounter (F5). None of these is "build inpatient now" (false confidence); all are "design the primitive/relationship so overlay→authority isn't foreclosed" (the opposite of false retreat).
